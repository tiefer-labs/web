# Security policy

## Reporting a vulnerability

Please write to **hello@tiefer.space** with a description of the problem,
the steps to reproduce it and the impact you expect. The same address is
published in https://tiefer.space/.well-known/security.txt.

- Do not open a public GitHub issue for a vulnerability.
- Do not test against other people's data, and do not run denial of
  service or automated scans that degrade the site for others.
- We will confirm receipt, keep you informed and credit you if you wish.

## Scope

The website at https://tiefer.space and the code in this repository.

## How the site is protected

See the "Security" section of `README.md` and
`docs/SECURITY-DECISIONS.md` for the accepted risks and trade-offs.
